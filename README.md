# Our team page

A simple team introduction page using HTML, CSS, and JavaScript. No installation or build required. Open index.html to preview.

## Add your card

1. Pull the latest main branch before editing.
2. Add your photo to images/ (use a simple unique filename).
3. Copy the member-card article in index.html, inside team-grid.
4. Change the name, major, photo, alt text, and fun fact. Use unique IDs for your name and fact; update aria-labelledby and aria-controls to match.
5. Preview index.html and check your photo and fun fact button.
6. Commit and push to main, then tell the next teammate.

## Publish on GitHub Pages

Keep index.html, style.css, script.js, and images/ at the repository root. The repository owner can select Settings → Pages → Deploy from a branch → main → / (root) → Save.
